# Agent instructions

## Design and UI copy

- Don't add explainer text to designs or app screens unless the owner explicitly asks for it. That includes source or data notes ("From your saved Tube map…"), disclaimers, footers, subtitles that restate a title, captions explaining how a feature works, and "coming soon" blurbs beyond the label itself.
- Keep only the copy a screen needs to work: titles, labels, values, button text, and errors.
- When unsure whether a line of text earns its place, leave it out.
